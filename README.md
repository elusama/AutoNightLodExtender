# AutoNightLodExtender
A Cities: Skylines 2 mod.
Auto Night LOD Extender automatically cranks up your LOD distance and active light source cap once the sun goes down, finally fixing vanilla's underwhelming nighttime lighting. Heads up: it hits the GPU pretty hard, so I'd recommend only flipping it on for screenshots.
- Auto Night LOD Scaling: Uses an independent night LOD multiplier that kicks in automatically after dark, rendering distant building lights way further out.
- Expanded Max Night Lights: Pushes the nighttime light source limit all the way up to 65,535, letting you see streetlights way off into the distance.
- (Experimental) Adaptive Dynamic LOD: Dynamically scales your LOD draw distance on the fly whenever your GPU starts bottlenecking, helping keep your target FPS stable.
